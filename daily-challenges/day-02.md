find. -maxdepth 1 - type f -name "*.html" 
Finds HTML files in the current directory only.

find. -type f -name "*.html"
Find all HTML files,including subfolders.

find terminal-git-project-type f -name "*.html"
Find HTML files in a specific directory.

find. -type f -iname "*.html"
Find HTML files without case sensitivity.
