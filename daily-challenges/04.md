Searching Files Using find and grep

## Objectives
- Learn how to locate files.
- Search for specific file extensions.
- Search for words inside files.
- Combine find and grep commands.

## Commands Practised

1. find . -type f -name "*.html"
2. find . -type f -name "*.js"
3. grep -n "Git" README.md
4. grep -r "function" .
5. find . -type f -name "*.js" -exec grep -n "function" {} +

## Learning Outcome

I learned how to locate files and search their
contents using Git terminal commands.
