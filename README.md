## Project Description

This project demonstrates practical knowledge of terminal commands, Bash scripting, Git version control, and collaborative software development.

It focuses on creating and managing project directories, searching files, automating project setup, managing Git branches, and resolving merge conflicts.

## Objectives

- Learn terminal navigation and file management.
- Create folders and files using terminal commands.
- Search files using `find` and `grep`.
- Develop an automated project setup script.
- Understand Git version control.
- Create, merge, and delete feature branches.
- Practise resolving merge conflicts.
- Document daily coding challenges.


## Collaboration

Collaboration is an important part of software development.

This project demonstrates how developers can work independently on different features and combine their work using Git.

### Collaboration Workflow

1. Create a feature branch from the main branch.
2. Make changes to project files.
3. Stage and commit the changes.
4. Switch back to the main branch.
5. Merge the feature branch.
6. Identify and resolve merge conflicts when they occur.
7. Test the final changes.
8. Delete merged feature branches.

### Branch Management

Example feature branches:

- `feature/terminal-documentation`
- `feature/daily-challenges`
- `feature/conflict-practice`

### Merge Conflict Resolution

A merge conflict was deliberately created by modifying the same section of a file in two different branches.

The conflicting changes were reviewed, manually resolved, staged, and committed.
